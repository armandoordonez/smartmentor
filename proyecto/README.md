# proyecto/

Este brief y los documentos de gestión del proyecto. El brief es un documento vivo: cada cohorte lo actualiza en lugar de escribir uno nuevo.

| Archivo | Contenido |
| --- | --- |
| [`brief.md`](brief.md) | El brief del proyecto: objetivos, alcance, arquitectura, métricas y cronograma |
| [`checklist.md`](checklist.md) | Lista de verificación del brief con responsables, avance de la fase y comparación de frontends. `scripts/avance.sh` calcula el porcentaje |
| [`decisiones-pendientes.md`](decisiones-pendientes.md) | Decisiones técnicas abiertas, con opciones y recomendación |
