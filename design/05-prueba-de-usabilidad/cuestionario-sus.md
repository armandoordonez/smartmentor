# Cuestionario SUS (System Usability Scale)

Se aplica al terminar las tareas. Cada afirmación se responde de 1 (totalmente en desacuerdo) a 5 (totalmente de acuerdo). Se pide responder rápido, sin pensar demasiado, y no dejar ninguna en blanco (si no sabe, marca 3).

| # | Afirmación | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Creo que me gustaría usar esta plataforma con frecuencia. | | | | | |
| 2 | La plataforma me pareció innecesariamente compleja. | | | | | |
| 3 | La plataforma me pareció fácil de usar. | | | | | |
| 4 | Creo que necesitaría ayuda de una persona con conocimientos técnicos para usar la plataforma. | | | | | |
| 5 | Las distintas funciones de la plataforma están bien integradas. | | | | | |
| 6 | La plataforma me pareció demasiado inconsistente. | | | | | |
| 7 | Imagino que la mayoría de las personas aprenderían a usar la plataforma muy rápido. | | | | | |
| 8 | La plataforma me pareció muy difícil de usar. | | | | | |
| 9 | Me sentí muy seguro(a) usando la plataforma. | | | | | |
| 10 | Necesité aprender muchas cosas antes de poder usar la plataforma. | | | | | |

## Cálculo del puntaje

1. Preguntas impares (1, 3, 5, 7, 9): respuesta − 1.
2. Preguntas pares (2, 4, 6, 8, 10): 5 − respuesta.
3. Sumar los 10 valores y multiplicar por 2,5. El resultado va de 0 a 100.

Lectura: el promedio de referencia es 68. La meta del brief para el piloto es **SUS ≥ 68**. Con 3 a 5 participantes el puntaje es orientativo: lo que más sirve en esta fase son las observaciones de las tareas.

Referencia: Brooke, J. (1996). SUS: A «quick and dirty» usability scale. En *Usability Evaluation in Industry* (pp. 189–194). Taylor & Francis.
